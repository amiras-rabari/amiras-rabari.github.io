CineSmart

A movie discovery platform for Canada. It answers three questions: what should I watch, where can I watch it, and what have I already watched, liked or saved?

View code on GitHub

System overview

  1. React single-page appReact 19 and TypeScript. TanStack Query handles server state, with optimistic updates that roll back on failure.
  2. Spring Boot API36 REST endpoints under /api/v1. Bearer access token plus an HttpOnly refresh cookie.
  3. PostgreSQL and RedisPostgreSQL holds the 16-table catalog and user activity. Redis holds short-lived security state: sessions, token blacklists and counters.
  4. Python ETL pipelinePulls from OMDb, TMDB and Watchmode, then validates, cleans and deduplicates into the catalog. Trending titles refresh daily.

The backend

The API is a modular monolith of about 5,200 lines across seven feature modules: identity, catalog, discovery, activity, recommendation, analytics and shared. Each module is split into api, application, domain and persistence layers.

Module dependencies stay acyclic through dependency inversion. For example, the catalog needs per-user flags that live in activity, so the interface lives in the shared module and activity implements it.

Session security

  • Two tokens. A 15-minute JWT access token held only in memory, and a random 256-bit refresh token in an HttpOnly, Secure, SameSite=Strict cookie.
  • Rotation with reuse detection. Each refresh consumes the token atomically and issues a new one. If an old token shows up again, the system treats it as theft and revokes every session for that user.
  • Login hardening. Unknown usernames still run a dummy BCrypt check, so response timing doesn't reveal which accounts exist. Five failures lock a user for an hour.
  • Atomic counters. Rate limits and lockouts use Redis Lua scripts, so a crash can't leave a counter without an expiry. Behavior during a Redis outage is tested both fail-open and fail-closed.

Search and recommendations

Typo-tolerant search over titles and people uses PostgreSQL pg_trgm trigram indexes with word_similarity ranking. The "For You" row is a content-based recommender that scores up to 300 candidates per user from their ratings, likes and watch history, and gives a reason for every pick.

Testing

Built test-first at every layer: JUnit with Testcontainers against real PostgreSQL and Redis, Vitest with MSW on the front end, and Playwright for end-to-end and accessibility checks.
